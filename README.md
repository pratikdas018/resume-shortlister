# AI Resume Shortlisting System (MERN)

An AI-powered resume shortlisting system built using the **MERN stack** that helps recruiters automatically analyze, score, and rank resumes based on job descriptions and required skills.

---

## 🚀 Features

- 📄 Upload single or multiple resumes (PDF)
- 🧠 Skill extraction from resumes
- 🎯 Role-based job templates:
  - MERN Stack Developer
  - Java Developer
  - Python Developer
  - AI / ML Engineer
  - Data Scientist
  - Data Analyst
  - Android Developer
- 📊 Resume scoring based on skill matching
- ✅ Matched & ❌ Missing skills display
- 🔝 Latest analyzed resumes shown first
- 💼 Professional HR-style dashboard UI

---

## 🛠 Tech Stack

### Frontend
- React (JavaScript)
- Tailwind CSS
- Axios
- Framer Motion

### Backend
- Node.js
- Express.js
- Multer (file upload)
- pdf-parse (PDF text extraction)

### Database
- MongoDB (Mongoose)
